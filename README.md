# React Currency Converter

A simple currency converter built with React. Converts between 150+ currencies using live exchange rates.

## Features

- Live exchange rates via ExchangeRate API
- Swap currencies with one click
- Clean dark UI

## Tech Stack

- React
- Tailwind CSS
- ExchangeRate API

## Getting Started
```bash
git clone https://github.com/musawerxd/react-currency-converter\
```
```bash
cd react-currency-converter
```
```bash
npm install
```
```bash
npm run dev
```
